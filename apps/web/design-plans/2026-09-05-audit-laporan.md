## Design language

- **Audited surface:** Dashboard admin LAZISNU — 8 halaman di `src/app/dashboard/*` (`assignments`, `audit-log`, `cans`, `master`, `overview`, `reports`, `resubmit`, `users`, `wa-monitor`) + layout bersama + 15 komponen di `src/components/ui/*` + 1 halaman login di `src/app/(auth)/login/`
- **Design sources (current & governing):**
  - `.agents/rules/12-standar-ui-web.md` (609 baris, dokumen utama) — palet, layout, dimensi presisi, pola toolbar/table/pagination/modal
  - `.agents/rules/07-pedoman-web.md` (diacu oleh AGENTS.md) — pedoman mobile-first + dashboard
  - `src/components/Sidebar.tsx` + `src/app/dashboard/layout.tsx` (Head/Toolbar/Table/Modal pattern dipakai konsisten)
- **Documented decisions:**
  - Palet tetap 7 token + 6 izin warna hardcoded (lihat §1 standar)
  - Layout baku: Header Section → Toolbar Section → Table Container + Pagination → Modal
  - Dimensi presisi: 35px (search), 36px (filter pill/dropdown/reset), 32×32px (icon button tabel), 44×44px (mobile touch)
  - Variasi tombol header: Primer `bg-[#EAD19B]`, Sekunder `text-[#EAD19B] hover:bg-[#EAD19B]/10`, Bulk Cetak, Bulk Hapus
  - Toolbar background WAJIB `#6B9E9F` (Muted Teal)
  - Mobile-first 360px; breakpoint `xs:` DILARANG (pakai `sm:`); zoom viewport TIDAK boleh dinonaktifkan
- **Governing owners and consumers:**
  - Owners: `12-standar-ui-web.md` adalah sumber primer; `src/components/ui/*` adalah implementasi yang dipakai di semua halaman
  - Consumers: 8 halaman dashboard (kecuali login) + 1 halaman login + 1 layout dashboard
- **Explicit exceptions:**
  - `login/page.tsx` memakai estetika glass + glow effect berbeda (satu-satunya halaman publik di sini) — BUKAN pengecualian tertulis, hanya implicit. **Butuh klarifikasi: apakah halaman login ini di-scope oleh standar yang sama? Standar hanya membahas "halaman modul dashboard" (§2), jadi login mungkin di luar cakupan.**
  - `error.tsx` (56 baris) tidak memakai Header/Toolbar/Table — implicit exception karena page-error
  - `loading.tsx` (35 baris) skeleton tidak memakai pola toolbar — implicit exception

## Improve first

**F1 (Palette system via Tailwind v4 @theme tokens)** — Highest leverage.

**Mengapa:**
- Menyeret 5 file primitif (Button, Badge, Card, Modal, Skeleton, Table, EmptyState) yang dipakai di 8 halaman dashboard
- Setelah di-fix, semua halaman otomatis koheren tanpa edit per-halaman (drift dicegah)
- Tailwind v4 `@theme inline` adalah cara native (sesuai stack yang sudah Anda pakai)
- Sekaligus menutup gap dengan `12-standar-ui-web.md` §1 yang sekarang hanya jadi dokumen tanpa enforcement di kode
- Impact ratio tertinggi: 1 patch token-level = 8 halaman × 15 komponen konsisten

**Bukan F2 (metadata)** karena F2 adalah 1 file saja (`layout.tsx`) — penting tapi tidak serumit F1 dalam hal koordinasi.

**Bukan F3 (a11y Modal)** karena a11y kompleks dan per-komponen; ideal sebagai PR kedua setelah F1.
