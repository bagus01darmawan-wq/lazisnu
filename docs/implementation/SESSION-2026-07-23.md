## Root Cause Docker Build Error (Terverifikasi)

Dokumen sesi sebelumnya salah mengidentifikasi root cause. Masalah sesungguhnya:

> **pnpm workspace tidak hoist devDependencies** (`typescript`) ke root `node_modules/`. Saat multi-stage Docker meng-copy root `node_modules` antar stage, symlink workspace (`apps/backend/node_modules/typescript`) tidak ikut.

**Fix**: Gabungkan `deps` + `build` menjadi satu stage. pnpm install + compile terjadi di environment yang sama sehingga symlink valid.

```dockerfile
# BEFORE (broken):
FROM base AS deps
RUN pnpm install
FROM base AS build
COPY --from=deps /app/node_modules node_modules  # symlink putus!
RUN node node_modules/typescript/bin/tsc         # ERROR: not found

# AFTER (fixed):
FROM base AS build
RUN pnpm install  # install + compile dalam stage yang sama
COPY . .
RUN node apps/backend/node_modules/typescript/bin/tsc  # ✅
```
