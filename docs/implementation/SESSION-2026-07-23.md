## Masalah Diketahui

### Docker Build Gagal
Docker build di Tencent Cloud VM gagal karena pnpm workspace dengan hoisting tidak kompatibel dengan multi-stage Docker build. Binary `tsc` dan `next` tidak bisa ditemukan meskipun sudah diinstall.
- File: `apps/backend/Dockerfile`, `apps/web/Dockerfile`
- Root cause: pnpm hoists semua dependencies ke root `node_modules/.bin`, tapi binary symlinks tidak berfungsi saat di-copy antar stage
- Solusi yang sudah dicoba: 5 iterasi (filter install, full install, ENV PATH, npx, node_modules/.bin/, typescript/bin/) — semua gagal
- **Solusi yang disarankan**: build TypeScript di host, Docker hanya copy `dist/` + install production deps saja

### SSH ke VM Gagal
SSH dari mesin lokal ke VM Tencent Cloud gagal. VNC console berfungsi.
- Root cause: SSH key tidak bisa diautentikasi meskipun public key sudah dipasang
- Workaround: transfer via `git push` → `git pull` di VM via VNC
