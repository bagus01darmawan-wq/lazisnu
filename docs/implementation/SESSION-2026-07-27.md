## 2. Bug Ditemukan & Diperbaiki

### Bug 1: Redis Protected Mode (Staging)
**Akar:** Redis 7 Alpine di Docker staging masih `protected-mode yes`, menolak koneksi dari container lain → ioredis EPIPE error flood.

**Solusi:** `command: redis-server --protected-mode no` di `docker-compose.staging.yml`.

### Bug 2: Supabase Staging DB IPv6-only
**Akar:** `db.ngskcwwjwxsvjrswomkf.supabase.co` hanya resolve ke IPv6, VM tidak punya akses IPv6 → ECONNREFUSED / "Network unreachable". Production tidak kena karena sudah pakai pooler URL (IPv4).

**Solusi:** Enable Connection Pooler di Supabase dashboard → pakai pooler URL (IPv4):
```
DATABASE_URL=postgresql://postgres.ngskcwwjwxsvjrswomkf:...@aws-1-ap-northeast-2.pooler.supabase.com:6543/postgres?pgbouncer=true
DIRECT_URL=postgresql://postgres.ngskcwwjwxsvjrswomkf:...@aws-1-ap-northeast-2.pooler.supabase.com:5432/postgres
```

**File:** `apps/backend/.env.staging`

### Bug 3: JWT_SECRET Required
**Akar:** `env.ts` masih me-require `JWT_SECRET` (deprecated). Tanpa ini server gagal start dengan `❌ Invalid environment variables`.

**Solusi:** Tambah `JWT_SECRET=staging-legacy-deprecated-key-replace-soon` di `.env.staging`.

### Bug 4: Nginx Staging Blocks Belum Ada di VM
**Akar:** `nginx/nginx.conf` lokal sudah ada staging server blocks tapi belum di-copy ke VM.

**Solusi:** `scp nginx/nginx.conf → /opt/lazisnu/nginx/nginx.conf → nginx -s reload`.

## 5. Catatan Penting

1. **Pooler wajib untuk Supabase di VM tanpa IPv6.** Production sudah pakai pooler dari awal (`aws-1-ap-southeast-1.pooler.supabase.com`). Staging baru di-enable session ini (`aws-1-ap-northeast-2.pooler.supabase.com`).
2. **`NODE_OPTIONS=--dns-result-order=ipv4first`** ditambahkan di Dockerfile untuk jaga-jaga, meskipun problem sudah solved dengan pooler.
3. **Orphan container warning:** Staging compose pakai `lazisnu_default` external network, jadi `docker compose` mendeteksi container production sebagai orphan. Bisa diabaikan atau pakai `-p staging` project name.
4. **BullMQ warning:** Redis staging pakai `volatile-lru` (bawaan). BullMQ rekomendasi `noeviction`. Tidak fatal untuk staging.
