## 3. Kesiapan Migrasi VM (Plug-and-Play)

### 3.1 Inventarisasi

| Aset | Lokasi | Migrasi |
|---|---|---|
| Source code, compose, nginx conf, prometheus, scripts | Git (`origin/main`) | `git clone` |
| Secrets (.env, env.backup-*) | `/opt/lazisnu/secrets/` (root:root 600) | Via bundle export → R2 |
| Sertifikat SSL | `/opt/lazisnu/nginx/certbot` (bind mount nginx; **gitignored**) | Via bundle export |
| Cron (root crontab + `/etc/cron.d/lazisnu-backup-health`) | VM | Via bundle export |
| sshd_config, sysctl (`overcommit_memory=1`, persist di `/etc/sysctl.conf`) | VM | Via bundle export |
| Backup DB (prod & staging) | R2 `backups/`, `backups-staging/` | Sudah offsite |
| Backup Kuma | R2 `kuma/` | Sudah offsite |
| Grafana/Prometheus history | bind mount `grafana-data/`, `prometheus-data/` | Opsional (`--with-data`) |
| Keystore APK | **Server EAS** (terikat akun) | Tidak ikut VM — kredensial EAS kritis |

### 3.3 Deliverables

- **`docs/MIGRATION-VM.md`** — runbook 7 bagian: prasyarat EAS, export bundle, provision VM baru (Ubuntu + Docker + security group), restore bundle + deploy (clone → secrets → sysctl → compose up → CI deploy tag), DNS (5 record, TTL rendah), verifikasi checklist, teardown 48-72 jam + rollback plan.
- **`scripts/vm-migration-export.sh`** — bundel artefak non-git (secrets, cron, nginx/certbot, sshd_config, sysctl; `--with-data` untuk grafana/prometheus history) → tar.gz → R2 `migrasi/` + verifikasi ukuran.
  - **Kendala**: aws-cli 1.22.34 multipart upload ke R2 gagal SSL EOF (file 38MB) → workaround `s3.multipart_threshold=128MB` (single PUT) + `--cli-read-timeout 600`. Teruji: bundle ringan 17.7KB instan; `--with-data` 38MB sukses ±5 menit.
  - Catatan: certs ada di `/opt/lazisnu/nginx/certbot` (bukan `/etc/letsencrypt`) — sudah benar di script.
