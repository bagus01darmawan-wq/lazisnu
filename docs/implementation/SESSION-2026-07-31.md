## 1. Diagnosa: CI Deploy-Staging Failure

### Root Cause

CI `deploy-staging` gagal setelah `docker compose up -d` karena backend container restart loop:

```
Cannot find module '/app/apps/backend/dist/server.js'
```

**Analisis 3 langkah:**
1. Dockerfile ([`apps/backend/Dockerfile` line 37](file:///c:/Users/user/Documents/lazisnu/apps/backend/Dockerfile#L37)) → CMD: `node apps/backend/dist/index.js` ✅
2. [`docker-compose.staging.yml`](file:///c:/Users/user/Documents/lazisnu/docker-compose.staging.yml) → ada `command: ["node", "apps/backend/dist/server.js"]` ❌
3. File `server.js` memang **tidak ada** di build output — entrypoint benar adalah `index.js`

`command:` di compose **override** CMD Dockerfile. Solusi: hapus baris `command:` agar Dockerfile CMD yang jalan.

**Kronologi kegagalan CI sebelumnya:**
| Attempt | Error | Fix | Commit |
|---------|-------|-----|--------|
| 1 | `git checkout origin/main` conflict untracked file `scripts/kuma-setup-monitors.sh` | `git checkout -f` di ci.yml | `3107f35` |
| 2 | `Cannot find module .../server.js` | Hapus `command:` override di compose | `fb411fd` (sesi ini) |

Dua masalah independen di pipeline yang sama — debug satu per satu.
