## Pelajaran

1. **Uptime Kuma image tidak boleh di-set `user:`** — startup `chown` butuh root. Berlaku beda dari redis/prometheus/grafana (Sesi 30 Lanjutan 5).
2. **Bind-mount file + container lama = inode lama** — `restart`/`reload` nginx tidak cukup; butuh recreate container. Dan pastikan resource yang direferensikan config (cert) sudah ada SEBELUM recreate.
3. **SOP yang ditulis tanpa eksekusi nyata bisa salah asumsi** — DNS ternyata Hostinger (bukan Cloudflare), image punya curl bukan wget, volume named bernama `uptime-kuma-data`. Eksekusi langsung mengungkap kebenaran.
4. **`docker volume rm` gagal dengan "volume in use"** jika masih dipakai — tunggu 24 jam + pastikan container compose sudah pakai bind mount.
